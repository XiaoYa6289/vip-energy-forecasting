# ML Forecasting for Energy Commodity Markets

## Project Overview
This project develops a machine learning–based forecasting framework to predict short-term energy commodity price movements using macroeconomic and financial indicators.

## Objectives
- Build a time-series forecasting pipeline for energy commodity prices
- Apply machine learning models (e.g., Support Vector Regression, deep learning–based models)
- Perform feature engineering using macroeconomic and market indicators
- Evaluate model performance using MAE, RMSE, and R² metrics

## Methods
- Data preprocessing and feature engineering using Python
- Machine learning modeling (SVR and multi-model forecasting approaches)
- Time-series cross-validation for model selection
- Performance evaluation and error analysis
