## Description
The dataset contains:

- Energy commodity price data used for forecasting experiments
- Macroeconomic indicators serving as predictive input features
- Preprocessed time-series data prepared for machine learning modeling

## Notes
- Please download the dataset and place it in the `data/` directory before running the notebooks.
- File paths in the notebooks assume the dataset is stored locally in the `data/` folder.
